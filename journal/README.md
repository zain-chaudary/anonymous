# journal/

Append-only. One file per day: `YYYY-MM-DD.md`.

This is the agent's continuity. A new session has no memory of the last one —
only what's written here. Write for a reader who knows the repo but wasn't
present.

**Shape of an entry:**

```markdown
## HH:MM — short title

**Did:** what actually changed.
**Decided:** the choice made and the reason, so it isn't relitigated.
**Broke:** anything that failed or is still broken. Be specific.
**Next:** the single next action.
```

Never edit or delete old entries, even ones that turned out wrong. Corrections go
in a new entry that says so.
